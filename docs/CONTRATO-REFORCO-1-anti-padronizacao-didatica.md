# CONTRATO DE REFORÇO 1 — ANTI-PADRONIZAÇÃO DIDÁTICA (PIPELINE BAUER PREMIUM)

> Reforço enviado pelo Bauer para a aula 2 (estômago) e válido para todas as aulas seguintes.
> Governa a camada DIDÁTICA/TEXTUAL: Calibrador → Roteirista → Didata.
> Conflito com o contrato visual já foi resolvido pelo Bauer: aplicar sem questionar.

A unidade soberana da plataforma é a PÁGINA. Cada página = decisão pedagógica própria, com missão, estratégia, ritmo, imagem, quiz e conexão com prova próprios.

Hierarquia de conflito:
- estética vs profundidade → vence profundidade
- padronização vs didática específica → vence didática específica
- resumo vs fidelidade às minúcias → vence fidelidade
- imagem bonita vs explicação completa → vence explicação completa
- criatividade vs aula → vence a aula
- conteúdo genérico vs foco residência → vence prova de residência

A plataforma deve ensinar MELHOR que o professor ao vivo, sem se afastar do que ele deu.

## DNA obrigatório por página (sem isto a página é inválida)
- Pergunta central, Objetivo cognitivo, Gatilho de prova, Risco principal, Estratégia didática dominante, Recurso visual obrigatório, Minúcias obrigatórias (falas/dicas/exceções do professor que não podem sumir), Quiz da página.

## Gatilhos objetivos para escolher a didática (não opcionais)
- conduta sequencial/decisão/emergência → algoritmo/fluxograma/árvore
- 2+ entidades parecidas → comparação ativa / tabela diferencial / "não confundir com"
- fisiopatologia/farmacologia/mecanismo → causal passo a passo + SVG de mecanismo
- achado visual/imagem/anatomia/EDA/peça/radiologia → imagem real comentada ou ilustração guiada
- critérios/classificações/estadiamento/scores → tabela estruturada + mnemônico
- exceções/contraindicações/pegadinhas → bloco de alerta + contraste com erro + questão de armadilha
- dica/mnemônico do professor → bloco destacado, nunca diluído
- conteúdo teórico → "como isso vira enunciado?"
- sequência temporal → linha do tempo/etapas

## Anti-repetição entre páginas
Páginas consecutivas NÃO repetem a mesma arquitetura didática dominante sem justificativa. Proibido molde fixo (ex.: definição→explicação→imagem→quiz repetido). Variar ritmo, abertura, recurso visual, interação, tipo de quiz, organização interna.

## Criatividade ancorada
Permitido: reorganizar, aprofundar, clarear, destacar prova, analogia fiel, mnemônico fiel, comparadores, fluxo decisório a partir de condutas ensinadas, exemplos fiéis, palavras-chave de banca.
Proibido: inventar conduta não dada, trocar prioridade do professor por livro genérico, conteúdo externo que desvie foco, mudar sentido de dica, transformar exceção em regra, omitir ressalvas, analogia imprecisa, mnemônico que simplifica demais, expandir além da prova.

## Não resumir: aprofundar até minúcias
Minúcia obrigatória = professor enfatizou / deu dica / usou exemplo / disse que cai-confunde-presta atenção / muda diagnóstico-conduta-gabarito / diferencia parecidos / define exceção / aparece em classificação-score-critério / é palavra-chave de enunciado / é erro comum / é pegadinha provável / é detalhe visual / é frase-síntese de raciocínio. NÃO pode sumir.

## Foco absoluto em residência médica BR
Público = médico/estudante avançado mirando residência tier alto. Toda página tem ≥1 conexão explícita com prova ("O que a banca quer", "Armadilha clássica", "Como aparece na questão", "Palavra-chave do enunciado", "Erro comum", "Ponto que muda conduta", "Não confundir com", "Resumo decisório", "Pista que entrega o diagnóstico", "Alternativa que parece certa, mas não é", "O detalhe que muda o gabarito"). Não mecânico — quando for a melhor forma de servir o conteúdo.

## Texto é o centro
Imagem/SVG/fluxo/interação são obrigatórios mas NUNCA substituem a explicação textual. Texto explica antes de mostrar, guia o olhar, não depende da imagem, não vira legenda/bullet pobre.
Estrutura mínima por página (ordem adaptável, função não-omitível): abertura com intenção → explicação central profunda → organização cognitiva → conexão com prova → recurso visual ancorado → consolidação/fechamento → quiz (≥2 questões, todas alternativas explicadas).

## Imagens reais e ilustrações: obrigatórias mas planejadas
Imagem real obrigatória quando há achado visual (EDA, peça cirúrgica/gastrectomia, radiologia, TC, lâmina, endoscopia). SVG obrigatório quando há mecanismo/fluxo/anatomia esquemática. Ficha do recurso visual: ID, tipo, o que mostra, por que existe, conceito que reforça, detalhe a observar, erro que evita, conexão com prova, posição, texto antes, legenda, texto depois, marcação/seta/zoom, qual imagem ruim evitar.

## Ancoragem fluida (5 movimentos)
1. Pré-âncora (por que vai olhar) 2. Orientação do olhar (o que ver primeiro) 3. Interpretação (o que significa) 4. Conexão com prova 5. Pós-âncora (transição de volta). Proibido "inserir imagem aqui". Imagem ainda não anexada → especificar como se encomendasse a imagem perfeita + criar espaço pedagógico completo.

## Quiz por página
≥2 questões, foco residência (clínico/decisório/pegadinha quando couber). Cada questão: enunciado, alternativas plausíveis, gabarito, explicação da correta E de TODAS as erradas (cada alternativa ensina algo), pista do enunciado, por que a errada tentava. Proibido explicação rasa ("errada porque não se aplica"). ≥1 questão de aplicação/decisão/diferencial/armadilha.

## Papéis
- CALIBRADOR: arquiteto estratégico. Plano micro por página (17 campos: título, função na sequência, pergunta central, objetivo cognitivo, estratégia dominante, gatilho, estrutura sugerida, minúcias, dicas/mnemônicos, armadilhas, conexão prova, recursos visuais, ficha inicial de cada visual, palavras-chave + cores, plano dos quizzes, riscos de execução ruim, critérios de aceitação). Não escreve página, não faz HTML, não plano genérico.
- ROTEIRISTA: arquiteto textual. Segue plano do Calibrador como contrato (pode melhorar, não apagar intenção; se mudar estratégia, justifica). Preserva minúcias, aprofunda, transforma dicas em blocos, escreve âncoras completas, ≥2 quizzes com todas alternativas explicadas. Não resume, não deixa imagem "pro Didata resolver".
- DIDATA: eleva o roteiro a experiência premium. Preserva conteúdo, mantém densidade, estética serve à didática, imagens ancoradas, cores semânticas, quiz completo, fechamento cognitivo. Não achata, não simplifica, não troca profundidade por estética, não vira template.

## Proibições absolutas (resumo)
Página sem DNA / sem objetivo / sem conexão prova; páginas consecutivas com mesma arquitetura sem justificativa; resumir em vez de aprofundar; apagar minúcias/dicas/mnemônicos/pegadinhas; página genérica que serviria pra qualquer aula; imagem decorativa/sem ficha/sem âncora; quiz <2 questões / sem explicar todas alternativas / explicação rasa; trocar profundidade por estética; fugir do foco residência; cores sem critério semântico.

## Régua final
Se a página parece só correta mas não soberana → não está pronta. Se é bonita mas não aprofunda → não. Se ensina mas não prepara pra prova → não. Se poderia ter a mesma estrutura de qualquer outra → não. Se não preserva minúcias do professor → não. Sensação alvo: inevitabilidade didática.
